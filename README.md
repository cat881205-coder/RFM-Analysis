# RFM-Analysis

# 📊 RFM 顧客分群商業分析報告 (Customer Segmentation Analysis)

本專案透過 **RFM 模型** (Recency, Frequency, Monetary) 對 732 位顧客進行分群分析，並結合對角與對應變數之對角矩陣散佈圖（Pair Plot）評估客群特徵，為企業制定精準的行銷與營運策略。

---

本數據集總計 **732 位顧客**，貢獻總營收約為 **NT$ 23,926,393**。依據 RFM 特徵共劃分為四大群體：

## 🔍 客群畫像與視覺化特徵分析

### 1. 💎 Medium 群體（頂級 VVIP）
* **特徵數據**：佔總人數 **15.57%**，貢獻 **36.51%** 營收。客單價最高（$76,632）、消費頻率最高（26.37 次），未消費天數極短（15.32 天）。
* **圖表表現**：於 F-M 散佈圖中位於右上方（紫色點），為顯著的高頻、高客單價族群。

### 2. 🎯 High 群體（核心主力顧客）
* **特徵數據**：佔總人數 **30.19%**，貢獻全公司最高的 **41.81%** 營收。購買頻率（19.32 次）與金額（$45,268）極為穩定。
* **圖表表現**：於 F-M 圖中緊鄰 Medium 群體下方（紅色點）。
> 💡 **帕雷托法則驗證**：`Medium` 與 `High` 合計僅佔 **45.76%** 的顧客數，卻貢獻了公司 **78.32%** 的總營收。

### 3. 🌱 Low 群體（基底 / 潛力顧客）
* **特徵數據**：佔比最高（**43.85%**），但營收僅佔 **18.95%**。消費頻率低（5.69 次）、購買間隔較長（44.48 天）。
* **圖表表現**：集中於 F 與 M 軸底部區域（藍色點），分佈廣但強度較弱。

### 4. ⚠️ Missing 群體（流失風險顧客）
* **特徵數據**：平均未消費天數高達 **182.72 天**（約半年），消費頻率（3.66 次）與金額（$8,570）均為最低。
* **圖表表現**：於 R 軸對應分佈圖中呈現極度偏向右側高值區間（綠色點），形成了顯著的流失峰值。
